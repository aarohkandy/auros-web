question: Can I get Windows back?
shortAnswer: Yes, by reinstalling it from Microsoft's media. A clean install erases the Windows that was there, and your files are safe in the archive either way.
group: trust
order: 4
---

Be clear about what a clean install does: it erases the Windows installation on that machine.
Your files are not in it, because they were copied off and verified first, and that archive is
on your disk, on your premises, before anything is written. But the Windows installation itself
is gone.

Getting Windows back means reinstalling it from Microsoft's installation media, then reinstalling
each program from its own installer, then restoring files from the archive. That is a per-machine
job, done by hand, and no part of it involves us. We have not timed it and we are not going to
put a figure on it for you, because the figure that matters is yours and it depends on how many
programs each machine had. For machines that shipped with Windows 10
or 11, the licence is usually recorded against the hardware, so a reinstall reactivates without
anybody typing a key. Test that on one machine before assuming it across a fleet.

There is a second option and we describe it the way we actually think about it. The installation
can keep Windows and add a boot menu, and it is offered only after your archive exists and has
been verified. Keeping Windows is more dangerous than replacing it, not less, because it means
shrinking a partition that has your live Windows on it. A clean install writes to a disk we have
already finished reading. If you want dual boot, have it, but do not choose it because it sounds
like the cautious one.

The genuinely cautious option is neither: image one machine, leave the rest alone, and use it
for a fortnight.
