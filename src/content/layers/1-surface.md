The laptop on the desk. It checks for a new image, downloads it in the background, and switches
to it the next time somebody restarts. The image it was running before is still on the disk.

If the new one cannot reach a login prompt twice, the machine goes back to the old one by itself.
Nobody is called and nobody has to notice.

A machine will tell you exactly what it is running and where that came from. That is one
command, and it is the only one on this page you would ever type at a machine.
