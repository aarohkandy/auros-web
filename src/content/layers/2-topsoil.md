The layer people actually touch. The eleven applications your staff use, the language the
interface is in, the keyboard layout, the wallpaper with your crest on it.

Applications come from Flathub and update themselves, separately from the operating system.
That separation is deliberate. The image owns everything that can take over a machine. The
applications own everything else. A browser update should not be an operating system event, and
an operating system update should not wait for a browser.

Language is not a setting somebody has to find. It is in the recipe, so it is in the image, so
it is what the machine has always been.
