A Windows program is a file built to run on Windows. Linux is a different operating system.
Moving the file does not move the thing that runs it, and there is no version of this that we
can fix by trying harder.

The test is not the brand. The test is how it gets onto the machine.

- If you log into it in a browser, it comes across, because a browser is a browser. Google
  Workspace, Microsoft 365 on the web, and every service your staff reach by typing an address
  work the same on the new machine as they did on the old one.
- If it has an installer, and it put a shortcut on the desktop, and it shows up in Windows under
  Apps and features, it does not come across.

Some of these have a Linux build, and some have a web version, and where they do, you install
that on the new machine. That is a reinstall, not a migration, and we are not going to blur the
two. Your licence, your login and your files are your own business; we do not touch them.

Our installer does not ask you to remember which is which. Before it writes anything, it reads
the actual list of installed programs off that actual machine, shows it to you, and makes you
acknowledge it. You find out on the screen in front of you, not in month two.
