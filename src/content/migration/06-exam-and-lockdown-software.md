title: Exam and lockdown software
verdict: does-not
oneLine: Lockdown exam software is designed to detect and refuse environments like ours. Assume it does not run.
examples:
  - "Lockdown browsers used for online exams and assessments"
  - "Exam board secure delivery and secure key software"
  - "Invigilation software that inspects what else is running on the machine"

This category is different from the rest, because it is not that nobody got round to building a
Linux version. It is that the entire job of the software is to establish that the machine is in
a known state, running a known operating system, with nothing else watching the screen.

Running it inside a compatibility layer is precisely the thing it exists to catch. If it did
run, it would not be doing its job, and the exam board would be right to say so.

Plan for exam machines separately. A small number of machines kept on Windows for the exam
window is a normal answer and costs less than discovering this in May.
