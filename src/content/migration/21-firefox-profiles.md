Firefox keeps its data in a profile folder, and it does not hand its keys to Windows the way
Chrome and Edge do. The folder is portable, so the profile moves and Firefox on the new machine
opens it as though nothing happened.

This is the one place where the migration is genuinely complete, and it is worth knowing before
the day. A school that moves staff to Firefox a few weeks beforehand has a much shorter list of
things to explain on the morning of.
