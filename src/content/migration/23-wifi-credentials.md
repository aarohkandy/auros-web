The installer reads the saved wireless profiles from Windows and carries them over, so the
machine associates by itself on the first boot rather than presenting a stranger with a network
picker.

Enterprise wireless that authenticates a user against a directory rather than a shared key is a
different case, and it lands in the same conversation as Active Directory. Ask first.
