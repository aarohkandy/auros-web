title: Printers
verdict: does-not
oneLine: The list of printers the machine had, and which one was the default, is not carried over.
examples:
  - "Network printers and copiers the machine already had"
  - "The default printer"
onLanding: false
order: 24
---

The installer does not record which printers the machine had or which one was the default. There
is no code in it that exports them. Note the printer names or addresses before you start, and add
them again on the new machine.

Print management clients are a separate question and have their own entry. So does anything that
needs a vendor driver for a finishing option nobody has used since 2019.
