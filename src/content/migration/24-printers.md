---
title: Printers
verdict: comes
oneLine: Mapped printers are carried over and set up on the new machine.
examples:
  - "Network printers and copiers the machine already had"
  - "The default printer, which stays the default"
onLanding: false
order: 24
---

The installer records which printers the machine had and which one was the default, and the new
machine is set up with them.

Print management clients are a separate question and have their own entry. So does anything that
needs a vendor driver for a finishing option nobody has used since 2019.
